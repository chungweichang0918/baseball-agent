# 測試影片與標註

影片檔（`.mp4`、`.mov`）不會進版本控制，只有 `labels/` 下的標註檔會。

## 1. 收集清單（目標 6–8 段）

| 檔名 | 主體 | 視角 | 數量 | 說明 |
|---|---|---|---|---|
| `p_side_XX.mp4` | 投手 | 側拍 | 2–3 | Demo 1、2 的主力素材；最好有一段能補上各球球種 |
| `p_cf_XX.mp4` | 投手 | 中外野轉播 | 2 | 驗證中外野視角的主體識別與出手點 |
| `b_side_XX.mp4` | 打者 | 側拍 | 1–2 | 打者分支（第 7 階段）用 |
| `b_cf_XX.mp4` | 打者 | 中外野轉播 | 1 | 驗證「依我方角色選分支」 |

每段影片的規格：

- 長度 10–15 秒，含 2–3 次完整的投球或揮棒動作。
- **盡量 60 fps 以上**。揮棒只有約 0.15 秒，30 fps 只拍得到 4–5 幀。
- **只留現場即時畫面**，剪掉特寫、慢動作重播和廣告。重播會讓所有時間指標失真。
- 轉播片段只用於課堂作業，報告中要註明來源。

## 2. 標註

```bash
python scripts/annotate_samples.py data/samples/p_side_01.mp4 --subject pitcher --view side
```

標註檔會存到 `labels/<影片檔名>.json`。按鍵說明見腳本開頭的說明文字，也會顯示在視窗底部。

### 階段定義

**投手**（每一球是一個週期）

| 鍵 | 階段 | 標在哪一幀 |
|---|---|---|
| 1 | `set` 固定姿勢 | 雙手在胸前合攏、完全靜止的第一幀 |
| 2 | `first_move` 動作啟動 | 離開固定姿勢、開始動作的第一幀（抬腿或手開始動） |
| 3 | `peak_leg_lift` 抬腿最高點 | 前導腳膝蓋最高的那一幀 |
| 4 | `foot_strike` 前腳著地 | 前導腳完全踩地的第一幀 |
| 5 | `release` 出手 | 球離開手指的那一幀（看不到球時，標手臂最前方的位置） |
| 6 | `follow_through` 跟進收尾 | 身體動作停下、重心穩定的第一幀 |

**打者**（每一球是一個週期，沒出棒也要標，並按 `k` 標記是否出棒）

| 鍵 | 階段 | 標在哪一幀 |
|---|---|---|
| 1 | `stance` 準備站姿 | 投手出手前，打者靜止的最後一幀 |
| 2 | `load` 預備動作 | 雙手開始往後拉、重心後移的第一幀 |
| 3 | `foot_down` 前腳落地 | 跨步腳完全著地的第一幀 |
| 4 | `swing_start` 揮棒啟動 | 雙手開始往前的第一幀（沒出棒則不標） |
| 5 | `contact` 擊球點 | 球棒碰到球或揮過本壘板的那一幀 |
| 6 | `finish` 收棒 | 揮棒動作結束的第一幀 |

### 標註原則

- 拿不準的階段寧可不標，不要猜。演算法評估時只比對有標的階段。
- 一段影片最好由同一個人一次標完，標準才一致。
- 球種代號：`FF` 四縫線、`SI` 二縫線、`SL` 滑球、`CU` 曲球、`CH` 變速球、`FS` 指叉球。不知道就留空。

### 標註檔格式

```json
{
  "video": "p_side_01.mp4",
  "subject": "pitcher",
  "camera_view": "side",
  "fps": 59.94,
  "frame_count": 899,
  "phase_names": ["set", "first_move", "peak_leg_lift", "foot_strike", "release", "follow_through"],
  "cycles": [
    {"index": 1, "phases": {"set": 12, "first_move": 58, "release": 131}, "pitch_type": "FF", "swung": null, "note": ""}
  ],
  "updated_at": "2026-10-29T15:00:00"
}
```
